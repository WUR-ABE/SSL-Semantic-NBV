# SSL-Semantic-NBV

**Self-supervised next-best-view planning for target-aware 3D reconstruction of plant parts.**

SSL-Semantic-NBV extends online self-supervised next-best-view planning from whole-plant reconstruction to task-relevant targets such as fruits and nodes. It uses a semantic information-gain metric, viewpoint-history modeling, and weak supervision to improve reconstruction under occlusion.
